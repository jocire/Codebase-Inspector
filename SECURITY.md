# Security

Codebase Inspector processes untrusted ZIP uploads. Its intended deployment is on a trusted developer machine, not as an unauthenticated public service. Please report suspected vulnerabilities privately via GitHub's repository security advisory reporting feature when enabled; do not disclose exploitable details in a public issue. Avoid sending confidential archives to externally hosted instances. The app has extraction limits but has not been independently audited for multi-tenant or Internet-facing deployment.
