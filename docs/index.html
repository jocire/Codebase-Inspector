Run it locally

git clone https://github.com/jocire/codebase-inspector.git
cd codebase-inspector
npm ci
npm start

Open http://localhost:4178 in your browser.

Why isn't the analyzer embedded here?

The archive analyzer needs a Node.js backend. GitHub Pages hosts static files only, so this site provides documentation rather than an upload form that cannot actually process archives. ZIP archives are processed by the backend you run, and should not be sent to untrusted deployments.
